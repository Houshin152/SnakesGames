这是一个用cpp写的贪吃蛇的项目，作为新手的第一个项目
该项目运行在windows端
操作系统：windows11
编程语言：cpp
开发工具：vscode(暂时定只有一个，我觉得后面如果要升级ui的话，cpp肯定是不够的)
编译器：gcc
版本管理：git
---

### **功能模块：**

#### UI:

开始界面：
开始游戏
最高分
退出游戏
游戏界面：
地图棋盘
蛇的外观
计分板
豆的外形(蛇吃的那个豆)
结束界面：
重新开始游戏
是否打破最高分
返回主界面
---

###### 蛇的移动：

蛇要自动往蛇头的方向移动，间隔时间需要考虑
蛇头的方向改变（wasd，方向键）
蛇头碰到边界---游戏结束
蛇头碰到豆---得分
蛇头不能碰到蛇身---蛇身的方向无法转过去
得分后蛇的长度增加一个单位
